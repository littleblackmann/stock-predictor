台股預測分析系統 v1.7.5
Windows 10 / 11 (64-bit)，需連線取得行情與新聞。

既有使用者：重新開啟程式，點「立即更新」；也可從設定的「關於 / 更新」檢查。

【短線分析】
輸入代號，例如 0050、2330 或完整代號 6488.TWO，按「短線分析」。
查看未來 1、3、5 個交易日相對於資料日收盤價的上漲／下跌機率。
每個期間都有獨立模型，畫面列出資料日、目標日與時間分段回測結果。
只使用完成的日線資料，台北時間 15:00 前不把當日日線當作已完成。
機率接近五成時顯示「接近五五波 · 暫觀望」；偏向明顯但回測未勝過基準時，
顯示「模型偏多／偏空（驗證不足）」，列出命中率或 Brier 機率誤差的具體原因。
觀望不當作明確方向訊號，本版沒有放寬門檻或提高顯示機率。
模型會在行情更新時重新計算；查詢相同資料使用快取。
新增大字模式與自選股總覽，總覽只讀取既有結果，不會呼叫付費 AI。

【OpenRouter 模型】
量化預測不需要 API Key；填入 OpenRouter Key 後可使用 AI 新聞分析。
在設定搜尋模型，查看每百萬 token 的參考費用，也能按「更新模型清單」。
內建清單取自 OpenRouter 公開目錄，包含 GPT-6.1 Sol、Claude Sonnet 5.5、
Claude Opus 5.5、GPT-6 Astra、Gemini 3.8 Flash 等選項。
更新程式或模型清單不會替換原本選好的模型。可用性及實際費用依帳號與供應商為準。
新聞 AI 用於解釋新聞，不直接改寫量化機率；找不到新聞時會明確顯示無資料。
設定 → API 設定 → 新聞搜尋來源：預設 Perplexity，直接共用 OpenRouter Key 和已選 AI 模型，不需另一把 Key。
每次新聞分析預設最多搜尋 1 次、每次最多 5 筆來源；可選 1～3 次與精簡／標準／詳細資料量。
Perplexity 搜尋參考費用 US$0.005／次，另計 AI token 費；免費 AI 模型也可能產生搜尋費，以 OpenRouter 實際計費為準。
同股、同模型、同搜尋設定的成功分析可在 30 分鐘內重用；分析面板會顯示搜尋時間、快取及可點開的來源。
仍可選 Brave Search（原 Key 保留）或 Google News RSS（不加收搜尋費，AI 分析仍計費）。
搜尋失敗時預設使用 RSS 備援並顯示原因；可在設定關閉備援。餘額／金鑰異常不重複嘗試 AI 分析。
未取得可核對來源或分析不完整時，不把 AI 猜測當成近期新聞，新聞不改寫 1／3／5 交易日模型機率。

【紀錄與驗證】
1、3、5 日紀錄分開保存，同一資料日、目標日和模型版本不重複覆寫。
目標日行情完成後才回填結果；缺少精確目標日資料時繼續等待。
「機率對照」以 50% 分界檢查機率偏向與實際收盤，包含觀望；剛好 50% 不評分。
「方向對錯」只評分當時明確方向；觀望顯示「觀望不評分」，不事後改寫原判斷。
原有新版觀望紀錄一旦回填收盤，也能直接顯示機率對照，不必刪除或重新分析。
更新結果會分別顯示尚未收盤、指定日行情缺漏、連線失敗或日期異常，可再次重試。
主來源回傳空資料或缺日會嘗試行情備援，兩個比較價格使用同一來源的還原價格。
舊版紀錄仍可查看，但不混入新版命中率，避免不同日期定義造成誤導。
恢復舊版未完成紀錄回填；因舊版只有查詢日期，沿用查詢日前最近交易日為基準、
查詢日後首個交易日為目標的推定規則，保留舊版標記，既有已驗證結果不改寫。
首次回填舊版前另存 .pre-v1.7.5-backfill.bak，日期欄滑鼠提示會說明推定限制。
歷史回測不代表未來報酬，也不包含交易成本。本軟體提供研究參考，不保證獲利。

【開發者】
啟動：python main.py
測試：python -m unittest discover -s tests -v
打包：python build.py
隔離診斷：python main.py --diagnose OUTPUT_DIR [--network-smoke]
診斷不使用現有 API Key；--network-smoke 只測行情及交易日曆，不呼叫付費 AI。
現行量化路徑：models/short_term.py，使用分時訓練、獨立校準與保留時段驗證。
舊 Transformer 程式與模型保留供研究；正式短線預測不載入舊模型。
