# v1.7.5 預測說明與實際結果回填

## 問題與原因

使用者提供 0050 與預測紀錄截圖。52.1% 接近五五波；3／5 日即使機率為 65%／73%，歷史命中率仍低於各自基準。原本程式把兩種情況都顯示為「方向不明」。這是保守訊號門檻，不是 Perplexity 搜尋故障。模型同時要求命中率高於基準、Brier 誤差低於基準。

新版觀望紀錄已有實際漲跌，但 correct 留空是原先設計，介面只顯示破折號容易誤認為沒有回填。v1.7.0 起的回填另行排除了所有 legacy，導致舊版未完成紀錄永久停留。Yahoo 回傳空資料沒有觸發備援；缺日與連線失敗也都只回傳 0，手動畫面誤報已是最新。

截圖 2026/10/12 00:18 的目標為當日收盤，當時尚未到 15:00 完整日線時間，繼續等待屬正常。

## 修正

- 區分「接近五五波 · 暫觀望」與「模型偏多／偏空（驗證不足）」，主面板、三期限卡片及狀態通知共用說明。另以可換行文字說明命中率或 Brier 未優於基準；保留原機率、模型、門檻及當時訊號。
- 紀錄增加衍生顯示欄「機率對照」：>50% 對照上漲、<50% 對照未上漲，50% 不評分，包含已驗證的觀望分析。「方向對錯」維持只評明確方向，觀望顯示不評分。兩種統計分開，歷史原始判斷不改寫，不把此對照宣稱為可獲利交易訊號。
- 舊版未回填紀錄恢復處理，沿用舊查詢日定義推定基準日／目標日；保留 legacy 身分及原已驗證結果，不混入新版統計。首次寫入前保存 `.pre-v1.7.5-backfill.bak`，日期滑鼠提示說明推定限制。
- 只抓已到完整收盤的紀錄；空資料或指定日缺漏嘗試 Yahoo chart 備援。同一筆比較的兩個還原價格來自同一次回應，不混合還原比例，不以其他交易日冒充缺失日期。
- 手動更新顯示已回填、尚未收盤、缺日、行情取得失敗、日期異常數量；失敗保留原資料供重試。檔案讀寫失敗仍回傳 UI 訊號，按鈕可恢復操作。
- 原回填 API 預設仍回傳 int，手動介面改用 details report。鎖定與原子寫入保留，回填中新增的紀錄不會被覆蓋。
