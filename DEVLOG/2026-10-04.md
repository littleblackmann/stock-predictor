# 2026-10-04 · v1.7.0 短線分析與更新維護

使用情境：使用者媽媽在另一台 Windows 電腦使用已安裝程式，主要看隔天到幾天內的走勢，透過 GitHub Releases 更新。AI 供應商為 OpenRouter。

## 問題與修正

- 舊特徵工程刪除最後一列，推論因此落後一日。現在保留最新列供推論，未知標籤維持 NaN，1 / 3 / 5 日標籤以原始交易日建立。
- 舊 Transformer 全資料訓練與後續 CV 不能提供可信的保留時段驗證；正式路徑改用每個時間區段重新訓練、校準的 LightGBM。Transformer 原碼保留並修正序列標籤對齊，但不載入舊模型做正式預測。
- 採三段外部時間驗證；訓練、校準、測試間隔至少涵蓋預測期間，避免重疊標籤跨入後段。僅在訓練資料判定有效特徵。回報命中率、Brier score、歷史先驗基準與樣本數。
- 最後模型使用歷史訓練段與較近校準段重新建立。資料內容指紋快取能識別修訂行情；沒有把回測結果說成實盤勝率。
- 歷史籌碼不足的欄位先從正式特徵排除，避免以未知資料的零值訓練。新聞分析獨立呈現，不以主觀情緒調整機率。
- 交易日與收盤完整性統一使用台北時間；15:00 前排除當日日線。Yahoo 套件不可用時使用公開 chart 端點，必要時用 TWSE 官方月報補齊缺漏尾端上市行情。
- CSV 原子寫入與程序鎖避免背景更新遺失紀錄；同一預測不重複改寫，精確目標日收盤才回填。舊 9 / 10 欄 CSV 備份並遷移，舊紀錄不混入新統計。
- OpenRouter 清單由公開 API 取得文字模型，內建 2026-10-04 快照，支援搜尋、刷新、參考費用。刷新不傳送 API Key、不變更已選模型。AI 請求限制輸出長度、驗證完整回應與 JSON。
- 大字模式、自選股總覽、期間／日期標示與紀錄篩選。設定頁加上捲動區以保留小視窗操作。
- 更新保留 TLS 驗證，檢查 ZIP 路徑與封裝版本，不將 GitHub 原始碼 ZIP 當安裝包。打包使用版本化資料夾保留舊 dist；本次僅完整更新包。

## 驗證與邊界

驗證輸出存於未追蹤的 build/verification/。最終打包、升級與發布結果會在發布時補記。

- 原始碼隔離診斷成功：Qt 主畫面、設定、紀錄與總覽可建立；大字 1100px 截圖檢查。無讀取真實使用者 API Key。
- 實際行情 0050.TW 使用 2026-10-02 資料；目標日分別為 2026-10-05、10-07、10-12，正確跳過 10-09 休市與週末。
- 同次保留時段回測：1 日 53.07% 對基準 51.84%；3 日 53.53% 對 55.91%；5 日 52.96% 對 57.06%。3 / 5 日仍不如基準，顯示方向不明。這是一檔股票的歷史驗證，不是使用者媽媽的實盤命中率，也未計交易成本。
- OpenRouter 模型 ID、價格與參數取自公開目錄；未用使用者的 Key 進行付費推論，不宣稱每個帳號均可成功呼叫所有模型。
- 未遠端操作媽媽電腦；本機程式與公開更新端點驗證無法取代她電腦上的實際升級。

## 後續評估

先累積新版本實際前瞻紀錄，觀察各期間的命中率、機率校準與明確方向覆蓋率，再決定是否加入其他模型或新聞特徵。現階段的改善是消除已知錯位與驗證偏差，不宣稱更換模型即可保證股價預測變準。

## 打包修正

正式 EXE 測試發現 PyInstaller 從建置環境 PATH 誤收 Poppler 的 icuuc.dll；該 DLL 的 ICU 78 匯出符號與 Qt 所需 Windows ICU API 不相容，導致 QtWidgets 啟動失敗。封裝明確排除該同名 DLL 及附帶的 icudt78.dll，改用 Windows 系統 ICU。修正後的 EXE 已完成隔離 UI 與實際行情診斷，正式包重建後再次驗證。
