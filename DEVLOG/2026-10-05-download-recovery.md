# 2026-10-05 · v1.7.2 下載中斷處理與封裝縮小

使用者回報媽媽 v1.6.2 已能看到更新，但執行到一半顯示更新失敗；尚未取得媽媽電腦的錯誤日誌或失敗階段，不能直接斷言根因。

## 已確認問題與修正

- v1.6.2 與 v1.7.1 原本單次串流下載，socket timeout 為 120 秒（不是整個下載只能跑 120 秒）；下載中斷、提早 EOF、解壓錯誤均回傳 False，沒有重試或續傳。失敗時刪除暫存下載，下次從零開始。
- 完整 v1.7.1 ZIP 為 678,980,155 bytes；其中 TensorFlow 壓縮資料 304,592,330 bytes。正式 v1.7 起使用 LightGBM 的 1／3／5 日模型，不依賴舊 TensorFlow 模型；移除封裝中的 TensorFlow／Keras／LiteRT／TensorBoard，保留正式預測與 Qt 圖表所需環境。
- 新下載器最多五次嘗試，每次連線／讀取逾時 45 秒，使用 64 KiB chunk。保留已下載 bytes，使用 Range／If-Range 續傳；伺服器忽略 Range 時重新覆寫，避免串接重複資料。提早 EOF 不視為下載完成。
- 使用 Release size 與 GitHub asset SHA-256 檢查完整下載；拒絕錯誤範圍、大小及雜湊。損毀的 SHA-256 快取移除；連線中斷的快取保留於 AppData/update_cache。
- 下載、重試、CRC 驗證與解壓在 UpdateWorker 執行，GUI 透過 signal 更新進度；顯示目前階段及具體錯誤、日誌位置。完成下載後仍需驗證、解壓，不再把下載 100% 當作安裝完成。
- 解壓前檢查暫存磁碟與程式磁碟空間，既有 TLS、ZIP 安全路徑、版本檢查保留；使用者 Key、設定、自選股、模型與紀錄不隨包發布。
- 媽媽的 v1.6.2 仍使用舊下載器：發布較小完整包可降低下載負擔，但續傳與具體錯誤功能要在成功升級後生效。若她仍無法自動更新，需要透過瀏覽器下載完整包；未遠端操作她的電腦。

## 驗證

- 原有 32 項加新增 10 項，共 42 項 unittest 通過：中斷 partial bytes、提早 EOF、跨次續傳、忽略 Range、錯誤 Range／大小、SHA 損毀、已完成快取、重試上限、阻止錯誤包安裝及正確 ZIP 準備。
- 實際 Qt 主執行緒計時器在下載 worker 模擬等待期間仍運作；確認 IO 在其他執行緒，失敗訊息含具体原因。
- 公開 v1.7.1 資產實測 Range `1048576-1114111` 回應 206，下載 65,536 bytes 與本機已驗證 ZIP 同位置內容一致；報告 `build/verification/download-range-v171.json`。
- 舊 ZIP 最長相對路徑 137 字元，本機典型暫存解壓完整路徑 203 字元；沒有證據顯示此包在本機會超過 Windows 260 字元限制。

## 最終封裝驗證

- 完整 ZIP 350,983,858 bytes（約 351 MB），較 v1.7.1 減少 48.3%；SHA-256 `3cbe9263a4a73ec720e32b097e721419ec58b2db9d20464970f2098fa2011475`。
- 4,964 個 manifest 檔案的 ZIP CRC、安全路徑、包內及解壓後 SHA-256 一致性全數通過；沒有 TensorFlow／Keras 資料。舊格式假 Key、原模型選擇、自選清單、CSV 原始紀錄及備份保留。
- 從正式 EXE 的 PYZ 取出五個更新相關模組，18 項更新檢查、下載及 Qt 背景執行測試全數通過。
- 一般 Windows 繪圖模式的 EXE 診斷退出碼 0，圖表與介面截圖已檢視；軟體繪圖模式的 EXE 加實際 0050 行情診斷也退出碼 0，1／3／5 日與 373 個文字模型清單正常。未使用真人 Key 或付費 AI。
- 無螢幕測試最初發生 ucrtbase `0xc0000409`；對照 v1.7.1 也重現相同 GPU context lost，改用軟體繪圖可通過，一般 Windows 模式也通過。未修改系統繪圖設定或正式應用預設，證據保留於 `diag-baseline`、`diag-software`、`packaged-v172-default-windows`、`packaged-v172-windows`。
- 使用 v1.6.2 原始更新器讀取已驗證的本機新 ZIP 串流，完整下載 350,983,858 bytes、解壓 4,964 個檔案並產生更新 batch。攔截 installer 程序以避免關閉測試程式；另在隔離路徑執行原生 xcopy，同參數複製後全部 manifest 及版本一致。此項不是媽媽電腦的實際網路／關閉／重啟端到端測試。
